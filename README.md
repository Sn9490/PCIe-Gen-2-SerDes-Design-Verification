## PCIe Gen2 SerDes Design & Verification
Designed and verified PCIe Gen2 SerDes physical layer blocks including Scrambler, Descrambler, 8b/10b Encoder/Decoder, PISO, and SIPO. Developed a UVM-based verification environment and achieved functional verification closure.


### Design

Implemented:
- Scrambler
- Descrambler
- 8b/10b Encoder
- 8b/10b Decoder
- PISO
- SIPO

### Verification

Developed reusable UVM environment:
- Sequencer
- Driver
- Monitor
- Scoreboard
- Coverage Collector


### Features Verified
- Encoding/Decoding Correctness
- Data Integrity
- LTSSM State Validation
- Error Injection Scenarios


## Tools
- QuestaSim
- SystemVerilog
- Verilog


### Results
- 100% Functional Coverage
- Protocol Compliance Verified
